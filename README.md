# iSatCR

iSatCR: Satellite Network Computing and Routing Simulation

This project studies task forwarding, computation offloading, and resource information exchange in satellite networks with onboard computing capabilities. It combines orbital data, dynamic network topology, ground station access, packet transmission, computation queues, and reinforcement learning decisions to compare task processing and routing methods under changing network conditions and failures.

The main comparison includes ISACR, D3QN, DDQN, and PPO. The project also contains information aggregation ablations, comparisons of information propagation ranges, multiple constellation scenarios, and implementations related to GSJF, ICS, and GraphPR.
